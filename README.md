# فرم Login / Sign Up | Login / Sign Up Form

یک فرم ورود و ثبت‌نام تعاملی ساخته شده با **HTML, CSS و JavaScript**.  
An interactive login and sign-up form built with **HTML, CSS & JavaScript**.

## ویژگی‌ها | Features
- اعتبارسنجی فیلدها (خالی، ایمیل، رمز عبور)  
  Field validation (empty, email format, password)
- انیمیشن shake + border قرمز هنگام خطا  
  Shake animation + red border on error
- طراحی ریسپانسیو موبایل و دسکتاپ  
  Responsive design for mobile & desktop
- قابل استفاده روی **GitHub Pages**  
  Ready to use on **GitHub Pages**
